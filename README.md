# 🧠 SkillSense AI

### AI-Powered Career Intelligence Platform

> **Turn your technical skills into your next career move.**

SkillSense AI is a full-stack machine learning application that analyzes technical skills, predicts suitable career roles, identifies skill gaps, and provides a personalized learning roadmap.

Instead of stopping at career prediction, SkillSense AI turns the prediction into an actionable career development workflow.

## ✨ Features

### 🎯 Career Prediction
Analyze your technical skills and predict suitable career roles using machine learning.

### 🏆 Top 3 Career Matches
Get multiple possible career paths with confidence percentages instead of receiving only one prediction.

### 🔍 Skill Gap Analysis
Identify important skills that may be missing from your current career profile.

### 🗺️ Personalized Learning Roadmap
Receive recommended skills and learning steps based on the identified skill gaps.

### 📊 Career Intelligence Dashboard
View your:

- Primary career match
- AI confidence
- Top 3 career matches
- Skills analyzed
- Skill gaps
- Recommended next steps

### ⚡ FastAPI REST API
The machine learning model is exposed through a FastAPI backend.

### 🌙 Premium UI
Modern responsive interface with:

- Dark mode
- Interactive cards
- Micro-interactions
- Responsive design
- Premium visual styling
